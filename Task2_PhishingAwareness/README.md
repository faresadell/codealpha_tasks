# CodeAlpha_PhishingAwareness

**Cyber Security Internship — Task 2: Phishing Awareness Training**
CodeAlpha | Author: Fares

## 📌 Overview
An interactive, single-file training module that teaches people to recognize
phishing emails and the social engineering tactics behind them. Built as a
self-contained HTML page — no build step, no dependencies — so it can be
opened directly in a browser or hosted for free on GitHub Pages.

## ✨ What's inside
1. **What is phishing** — the core concept and its three common forms (mass phishing, spear phishing, smishing/vishing).
2. **Anatomy of a phishing email** — a realistic fake email with 5 clickable red flags (sender domain, urgency, generic greeting, mismatched link, fear-based threat), each with an explanation.
3. **Social engineering tactics** — the four psychological levers attackers rely on: urgency, authority, fear, and curiosity.
4. **Real-world examples** — two well-known incidents that show phishing's real financial impact.
5. **"Spot the Phish" quiz** — 4 realistic scenarios, scored interactively, with an explanation after every answer.
6. **Quick checklist** — the 3 things to check before clicking any link.

## 🚀 How to use it
Just open `index.html` in any browser — it's fully self-contained (HTML + CSS + JS, no external libraries).

To host it publicly (for the LinkedIn video / submission link):
1. Push this repo to GitHub as `CodeAlpha_PhishingAwareness`.
2. Enable **GitHub Pages** in the repo settings (Settings → Pages → Deploy from branch → `main` / root).
3. Share the generated `https://<username>.github.io/CodeAlpha_PhishingAwareness/` link.

## 🎓 What I learned
- The recurring structural markers of a phishing email (sender spoofing, link mismatch, urgency language)
- The psychological tactics (urgency, authority, fear, curiosity) that make social engineering effective
- How to translate awareness content into an interactive format that reinforces learning through practice, not just reading
